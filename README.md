
# Python Practices

Welcome to the **Python Practices** repository. This project serves as a structured collection of Python scripts, exercises, and code snippets documenting my progress and practical implementations while learning and mastering Python development.

---

## Repository Structure

The repository is organized into directories covering various programming fundamentals, algorithms, and practical use cases:

| Directory / Module | Description | Key Topics Covered |
| :--- | :--- | :--- |
| **src / scripts** | Core source code and script files | Modular Python scripts, automation tasks, and utility functions. |
| **exercises** | Algorithmic and problem-solving exercises | Practice challenges, logic implementation, and code katas. |
| **notebooks** | Interactive Jupyter notebooks (`.ipynb`) | Exploratory data analysis, interactive tutorials, and step-by-step logic. *(See the [notebooks branch](https://github.com/AlvaroFA/PythonPractices/tree/notebooks) for dedicated notebook workflows).* |

---

## Prerequisites & Requirements

To run these scripts locally, ensure you have the following installed:

* **Python** (version 3.8 or higher recommended)
* **Git** (for version control)
* **Visual Studio Code** (or any preferred Python-compatible IDE)
