# Python Practices & Jupyter Notebooks

Welcome to my **Python Practices** repository. This branch (`notebooks`) contains a collection of interactive Jupyter Notebooks (`.ipynb`) documenting my journey learning Python from scratch, exploring fundamental concepts, and working through practical exercises.

---

## Repository Structure

The notebooks are organized progressively to cover core programming concepts:

| Notebook / Topic | Description | Key Concepts Covered |
| :--- | :--- | :--- |
| **01_Basics** | Introduction to Python syntax and types | Variables, basic data types (`int`, `float`, `str`, `bool`), type casting, basic I/O. |
| **02_Control_Flow** | Making decisions and repeating tasks | Conditional statements (`if`, `elif`, `else`), `for` and `while` loops, break/continue. |
| **03_Data_Structures** | Managing collections of data | Lists, tuples, dictionaries, sets, and basic methods/manipulation. |
| **04_Functions** | Modular and reusable code | Function definition, parameters, return values, scope, and lambda functions. |
| **05_Exercises** | Applied coding challenges | Practical problem-solving and algorithmic exercises. |

*(Note: Update or expand this table as new notebooks are added to the branch).*

---

## Prerequisites & Requirements

To run and interact with these notebooks locally, ensure you have the following installed:

* **Python** (version 3.8 or higher recommended)
* **JupyterLab** or **Jupyter Notebook**
* **Git** (for version control)
